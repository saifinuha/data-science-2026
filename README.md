## 🛠️ Tools & Library yang Digunakan

Proyek ini menggunakan berbagai tools dan library Data Science, antara lain:

### **Bahasa Pemrograman:**
- **Python 3.x** — bahasa utama untuk semua analisis, pemodelan, dan visualisasi

### **Data Processing & Analysis:**
- **Pandas** — manipulasi data, agregasi DataFrame, dan pemrosesan transaksi
- **NumPy** — operasi numerik, komputasi matriks, dan manipulasi array

### **Visualisasi & Dashboard:**
- **Matplotlib** — plotting dasar, visualisasi grafik, dan kurva pembelajaran
- **Seaborn** — visualisasi statistik tingkat tinggi (heatmap, boxplot, pairplot, violin plot)

### **Machine Learning, Preprocessing & Association Rules:**
- **scikit-learn** — algoritma ML, pra-pemrosesan, evaluasi model, dan jaringan saraf dasar:
  - Preprocessing: `StandardScaler`, `MinMaxScaler`, `train_test_split`
  - Model Supervised: `LinearRegression`, `LogisticRegression`, `DecisionTreeClassifier`, `RandomForestClassifier`
  - Model Neural Network: `MLPClassifier`
  - Model Unsupervised: `KMeans`, `AgglomerativeClustering`
  - Evaluasi & Metrics: `accuracy_score`, `precision_score`, `recall_score`, `f1_score`, `roc_auc_score`, `confusion_matrix`, `classification_report`, `mean_squared_error`, `r2_score`
- **mlxtend** — Market Basket Analysis menggunakan `apriori` dan `association_rules`
- **SciPy** — hirarki clustering (`dendrogram`, `linkage`) dan fungsi statistik

### **Dataset Management & Integration:**
- **kagglehub** — pengunduhan dataset otomatis dari Kaggle (Telco Customer Churn)

### **Environment & Execution:**
- **Google Colab** — cloud-based Jupyter notebook environment
- **GitHub** — version control dan dokumentasi proyek

## 🚀 Cara Menjalankan Notebook

### **Opsi 1: Google Colab (Direkomendasikan)**

Semua notebook telah dioptimalkan untuk berjalan di Google Colab. Langkah-langkahnya:

1. Buka notebook dari link di tabel di atas
2. Klik tombol **"Open in Colab"** yang ada di bagian atas notebook
3. Jalankan setiap cell dengan menekan `Shift + Enter` atau klik tombol ▶️ di sebelah cell
4. Jika ada dataset yang diunduh via script (`kagglehub` atau URL), Colab akan mengunduhnya secara otomatis

**Keuntungan Google Colab:**
- ✅ Gratis dan tidak perlu instalasi
- ✅ GPU/TPU tersedia jika diperlukan
- ✅ Library utama sudah pre-installed

### **Opsi 2: Jupyter Notebook Lokal**

Jika Anda ingin menjalankan di komputer lokal:

#### **Prasyarat:**
```bash
# Install Python 3.x dan pip
python --version
pip --version
```

#### **Langkah Instalasi:**

1. **Clone atau download repository:**
   ```bash
   git clone https://github.com/saifinuha/data-science-2026.git
   cd data-science-2026
   ```

2. **Buat virtual environment (opsional namun direkomendasikan):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Untuk Linux/Mac
   # atau
   venv\Scripts\activate  # Untuk Windows
   ```

3. **Install dependencies:**
   ```bash
   pip install jupyter pandas numpy matplotlib seaborn scikit-learn scipy mlxtend kagglehub
   ```

4. **Jalankan Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```

5. **Buka file notebook** (misalnya `Pertemuan1_Saifin_Nuha_240401010257.ipynb` hingga `Pertemuan13_Saifin_Nuha_240401010257.ipynb`) dari browser yang terbuka, kemudian jalankan setiap cell.

## 📊 Kesimpulan Perjalanan Belajar Data Science (Pertemuan 1–13)

Perjalanan pembelajaran Data Science dari Pertemuan 1 hingga Pertemuan 13 mencakup fondasi dasar pemrogramam Python, pengolahan data mentah, visualisasi statistik, machine learning (supervised & unsupervised), hingga fondasi jaringan saraf tiruan (deep learning) dan NLP.

---

### 🔹 **Fase 1: Fondasi Data & Pra-pemrosesan (Pertemuan 1–3)**

- **Pertemuan 1: Fondasi Python & Data Science Tools**  
  Memahami variabel, tipe data, struktur data dasar (list, dictionary), kontrol alur, serta pemanggilan fungsi sebagai pondasi utama pengolahan data.
- **Pertemuan 2: NumPy, Pandas & Eksplorasi Data**  
  Menguasai operasi array multidimensi dengan NumPy dan manipulasi DataFrame menggunakan Pandas. Dilanjutkan dengan EDA awal pada dataset Titanic untuk mengidentifikasi statistik deskriptif dan tingkat kelangsungan hidup penumpang.  
  *Key Insight:* ~38.4% penumpang Titanic selamat, dengan tingkat kelangsungan hidup penumpang Kelas 1 mencapai 63% dibandingkan Kelas 3 (24.2%).
- **Pertemuan 3: Data Cleaning Pipeline**  
  Membangun alur pembersihan data yang terstruktur: deduplikasi, statistik pencocokan string, imputasi missing values (mean/median), serta deteksi outlier dengan metode Interquartile Range (IQR) pada data *Housing*.

---

### 🔹 **Fase 2: Visualisasi & Exploratory Data Analysis (Pertemuan 4–5)**

- **Pertemuan 4: Analisis Deskriptif & Visualisasi Data**  
  Menggunakan Matplotlib & Seaborn untuk mengungkap korelasi linier dan distribusi data Iris.  
  *Key Insight:* Ditemukan korelasi positif yang sangat kuat antara `petal_length` dan `petal_width` (r = 0.963).
- **Pertemuan 5: Multi-Panel Dashboard & EDA Komprehensif**  
  Merancang dashboard analisis multi-sudut pandang pada dataset Titanic menggunakan framework **"What, So What, Now What"** untuk memetakan pengaruh usia, jenis kelamin, dan tarif terhadap rasio keselamatan penumpang.

---

### 🔹 **Fase 3: Feature Engineering & Supervised Learning (Pertemuan 6–10)**

- **Pertemuan 6: Feature Engineering & Preprocessing**  
  Menerapkan teknik enkoding fitur kategorikal (One-Hot Encoding), pembagian dataset (*train-test split* berbasis stratifikasi), dan normalisasi skala (*StandardScaler*).
- **Pertemuan 7: Regresi Linier & Evaluasi Regresi**  
  Membangun model regresi linier untuk prediksi gaji berdasarkan faktor pengalaman dan tingkat pendidikan.  
  *Key Result:* Model mencapai nilai $R^2 = 0.974$ dengan $MAE = 1.649$ juta rupiah, membuktikan pengalaman kerja sebagai prediktor gaji utama.
- **Pertemuan 9: Evaluasi Model Klasifikasi**  
  Membandingkan performa model **Logistic Regression** dan **Decision Tree** pada dataset *Breast Cancer* Wisconsin.  
  *Key Result:* Logistic Regression unggul dengan nilai *Recall* sebesar 0.986 (sangat krusial pada domain medis untuk meminimalkan *False Negative* / kasus kanker yang tidak terdeteksi).
- **Pertemuan 10: Ensemble Learning & Customer Churn Prediction**  
  Mengimplementasikan **Random Forest Classifier** pada dataset *Telco Customer Churn* dengan optimasi hyperparameter dan evaluasi kurva ROC-AUC.  
  *Key Result:* Model mencapai akurasi 78% dan ROC-AUC 0.82 dalam mengidentifikasi potensi churn pelanggan.

---

### 🔹 **Fase 4: Unsupervised Learning & Market Basket Analysis (Pertemuan 11–12)**

- **Pertemuan 11: Clustering (K-Means & Hierarchical Clustering)**  
  Mengelompokkan segmentasi pelanggan tanpa label menggunakan **K-Means Clustering** dan **Hierarchical Clustering**.  
  *Key Result:* Pengujian metode *Elbow Method* dan visualisasi *Dendrogram* secara konsisten menunjukkan jumlah klaster optimal adalah $K=3$ (kelompok pelanggan Hemat, Menengah, dan Utama).
- **Pertemuan 12: Market Basket Analysis & Sistem Rekomendasi**  
  Menerapkan algoritma **Apriori** untuk menemukan pola aturan asosiasi (*Association Rules*) antar produk transaksi dan membandingkannya dengan metode rekomendasi berbasis konten (*Content-Based Filtering*).  
  *Key Result:* Ditemukan aturan asosiasi kuat antara pasangan `(Keju, Teh) -> (Telur)` dengan nilai *Lift* sebesar 2.38.

---

### 🔹 **Fase 5: Pengantar Deep Learning & NLP (Pertemuan 13)**

- **Pertemuan 13: Neural Networks (MLP Classifier) & Konsep NLP**  
  Membangun arsitektur *Multi-Layer Perceptron* (MLP) untuk menyelesaikan masalah klasifikasi dataset non-linier (*Synthetic Moons*) serta mempelajari konsep dasar arsitektur Deep Learning dan pemrosesan bahasa alami (NLP).  
  *Key Result:* Model neural network berhasil mempelajari batas keputusan (*decision boundary*) non-linier yang kompleks secara akurat tanpa *overfitting*.

---

### 💡 **Rangkuman Pembelajaran Utama (Key Takeaways):**

1. **End-to-End Data Pipeline:** Proses Data Science bersifat siklis dan berkelanjutan — dimulai dari pengumpulan data mentah, pembersihan data, eksplorasi visual, pemodelan statistik/ML, hingga evaluasi dan interpretasi bisnis.
2. **Kualitas Data & Preprocessing:** Data cleaning dan feature engineering menyumbang porsi terbesar dalam keberhasilan model Machine Learning ("Garbage In, Garbage Out").
3. **Pemilihan Metrik Evaluasi yang Tepat:** Pemilihan metrik evaluasi bergantung pada domain masalah. Pada klasifikasi medis (Pertemuan 9), *Recall* lebih diutamakan daripada sekadar akurasi; sedangkan pada regresi (Pertemuan 7), $R^2$ dan $MAE$ memberikan gambaran presisi prediksi.
4. **Fleksibilitas Paradigma Pemodelan:** Supervised learning efektif untuk prediksi bernilai kontinu/kategori terlabel, Unsupervised learning memberikan wawasan eksploratif terhadap pola tersembunyi/segmentasi data, dan Deep Learning memperluas kapabilitas pemodelan untuk batas keputusan non-linier yang kompleks.
